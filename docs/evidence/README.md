# Evidenze

Qui vivono le prove che un criterio di accettazione è soddisfatto (GOAL V8). Una milestone o un requisito non sono «completati» senza un'evidenza in questa cartella.

## Regole

- Una cartella per milestone: `docs/evidence/M1/`, `docs/evidence/M2/`, …; `docs/evidence/baseline/` per il lavoro fatto prima del piano.
- Ogni file di evidenza indica: requisito (REQ-xxx), comando o procedura, commit, host (es. «PC di sviluppo Windows 11»), data e ora, esito, limiti.
- **Solo dati sintetici.** Mai testo OCR di documenti veri, immagini, nomi, importi o percorsi personali. Per la prova sul campo (M8) entrano solo numeri riassuntivi.
- Output lunghi: un estratto con le righe che decidono l'esito, più il riassunto finale del runner (es. `660 passed, 1 skipped`).
- Le evidenze non si riscrivono: una nuova esecuzione è un nuovo file con la sua data.
